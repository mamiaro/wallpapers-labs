# wallpapers

Acá va cada iteración de wallpapers, una carpeta por fondo:

```
wallpapers/<estilo>/<fondo>/
  escritorio.jpg
  mobile.jpg
  vista.jpg
```

Para publicar un fondo: subir su carpeta acá y sumar su bloque arriba de todo en `wallpapers.json`, con `"id": "<estilo>/<fondo>"`.
El link queda `https://mamiaro.github.io/wallpapersLabs/?wallpaper=<estilo>/<fondo>`.
